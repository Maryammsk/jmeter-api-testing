# JMeter API Testing Assignment

This repository contains the files and resources used for **API Testing Assignment No. 2** during the 10Pearls SHINE Internship.

## Assignment Checklist

- [x] Created test plan in JMeter.
- [x] Added Thread Group, Samplers for GET, POST, PUT, PATCH, DELETE.
- [x] Used 2+ Listeners (e.g., View Results Tree, Summary Report).
- [x] POST: Created data.
- [x] GET: Retrieved same data.
- [x] PATCH: Updated a parameter.
- [x] DELETE: Deleted the data.
- [x] GET: Verified data is deleted (null/empty response).
- [x] Used CSV data with POST & verified via GET.
- [x] Uploaded files to GitHub repo.

## 📁 Files Included

- `API_Test_Plan.jmx` – Main JMeter test plan.
- `books.csv` – CSV file used for POST data.
- (Optional) Screenshots or listener result images.

## 🔗 How to Run

1. Open JMeter and load `API_Test_Plan.jmx`.
2. Ensure the local server (`localhost:3000`) is running with the API.
3. Run each sampler under the thread group.
4. Use listeners to review results.
